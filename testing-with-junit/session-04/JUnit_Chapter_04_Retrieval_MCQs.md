# JUnit Retrieval — Chapter 4
## Advanced JUnit Features — MCQ Exam Drill

> **Exam standard:** Choose the single best answer before checking the answer and explanation.
>
> The distractors are deliberately close. Focus on distinctions between **test definition vs invocation**, **argument sources**, and **parameterized vs dynamic tests**.

### 1. What problem does parameterized testing primarily solve?

A. It allows JUnit to execute tests without assertions.  
B. It reduces repetition when the same test logic must be run with different data.  
C. It replaces lifecycle methods.  
D. It allows production code to be generated automatically.

**Answer: B**

**Explanation:** Parameterized testing separates a reusable test structure from the data used to invoke it.

### 2. Which annotation identifies a parameterized test in JUnit Jupiter?

A. `@Test`
B. `@Parameterized`
C. `@ParameterizedTest`
D. `@TestTemplate`

**Answer: C**

**Explanation:** `@ParameterizedTest` identifies a parameterized test method.

### 3. Which statement best describes a parameterized test?

A. One test method can be invoked using multiple supplied argument sets.  
B. Multiple test classes are merged into one test.  
C. One assertion is executed multiple times automatically without data.  
D. A test is generated only after the application starts.

**Answer: A**

**Explanation:** The defining idea is one reusable test structure with multiple sets of arguments.

### 4. Consider:

```java
@ParameterizedTest
@ValueSource(ints = {1, 2, 3})
void shouldBePositive(int number) { }
```

How many argument values are supplied?

A. 1  
B. 2  
C. 3  
D. 4

**Answer: C**

**Explanation:** The source contains three values: `1`, `2`, and `3`.

### 5. What is the best mental model for `@ValueSource`?

A. Multiple columns of related data  
B. Simple individual argument values  
C. Data generated by another Java method  
D. Data loaded from a CSV file

**Answer: B**

**Explanation:** `@ValueSource` is intended for simple literal values supplied to the parameterized test.

### 6. Which source is most appropriate for enum constants?

A. `@ValueSource`
B. `@EnumSource`
C. `@CsvSource`
D. `@MethodSource`

**Answer: B**

**Explanation:** `@EnumSource` supplies enum constants.

### 7. Which source is most appropriate when each test invocation needs several values written directly in the annotation?

A. `@ValueSource`
B. `@EnumSource`
C. `@CsvSource`
D. `@MethodSource`

**Answer: C**

**Explanation:** Each CSV row can provide several arguments to one invocation.

### 8. Consider:

```java
@CsvSource({
    "2, 3, 5",
    "5, 4, 9"
})
```

What does each row represent?

A. One test class  
B. One test method definition  
C. One argument set/invocation  
D. One assertion

**Answer: C**

**Explanation:** Each row supplies one set of arguments for the parameterized test.

### 9. Which is the strongest distinction between `@ValueSource` and `@CsvSource`?

A. ValueSource is for JUnit 4 and CsvSource is for JUnit 5.  
B. ValueSource supplies simple values, while CsvSource can supply multiple values per invocation.  
C. ValueSource creates dynamic tests, while CsvSource creates static tests.  
D. They are identical except for their names.

**Answer: B**

**Explanation:** This is one of the most important source-selection distinctions.

### 10. Which source obtains arguments from a Java method?

A. `@ValueSource`
B. `@EnumSource`
C. `@MethodSource`
D. `@CsvFileSource`

**Answer: C**

**Explanation:** `@MethodSource` obtains arguments from a method.

### 11. Which source reads CSV data from a file?

A. `@CsvSource`
B. `@CsvFileSource`
C. `@ValueSource`
D. `@ArgumentsSource`

**Answer: B**

**Explanation:** `CsvFileSource` gets CSV data from an external file.

### 12. Which source is designed for a custom argument provider?

A. `@ArgumentsSource`
B. `@ValueSource`
C. `@EnumSource`
D. `@CsvSource`

**Answer: A**

**Explanation:** `ArgumentsSource` allows a custom provider to supply arguments.

### 13. Which pairing is correct?

A. `@ValueSource` → enum constants  
B. `@EnumSource` → Java method  
C. `@MethodSource` → arguments produced by a method  
D. `@CsvFileSource` → inline CSV strings

**Answer: C**

**Explanation:** The other pairings mismatch the source with its role.

### 14. Which pairing is correct?

A. `@CsvSource` → inline CSV-style data  
B. `@CsvFileSource` → enum constants  
C. `@ArgumentsSource` → simple literal integers only  
D. `@ValueSource` → external CSV file

**Answer: A**

**Explanation:** `CsvSource` supplies CSV-formatted arguments directly in the test annotation.

### 15. Which statement about a parameterized test is most accurate?

A. One test definition necessarily means one execution.  
B. One test definition can result in multiple invocations.  
C. Multiple argument sets are ignored after the first.  
D. Parameterized tests cannot use assertions.

**Answer: B**

**Explanation:** Each supplied argument set can produce a separate invocation.

### 16. A parameterized test receives five argument sets. What should you generally expect?

A. Five test invocations of the parameterized test structure  
B. One invocation containing five unrelated tests  
C. One invocation only  
D. Five test classes

**Answer: A**

**Explanation:** Each supplied argument set drives an invocation.

### 17. Which statement best describes `@MethodSource`?

A. It means the test method itself is the data source.  
B. It tells JUnit to obtain arguments from a source method.  
C. It loads data from a CSV file.  
D. It supplies only enum constants.

**Answer: B**

**Explanation:** The source method provides the argument sets.

### 18. Which source is the most natural choice for:

```text
input, expected
2, 4
3, 9
4, 16
```

when the data is written directly in the test?

A. `@ValueSource`
B. `@CsvSource`
C. `@EnumSource`
D. `@ArgumentsSource`

**Answer: B**

**Explanation:** There are multiple values per invocation, and the data is inline.

### 19. Which source is the most natural choice for:

```text
MONDAY
TUESDAY
WEDNESDAY
```

where these are enum constants?

A. `@EnumSource`
B. `@ValueSource`
C. `@CsvSource`
D. `@MethodSource`

**Answer: A**

**Explanation:** The data is an enum.

### 20. Which source is the most natural choice when complex test objects must be constructed through Java code?

A. `@ValueSource`
B. `@MethodSource`
C. `@EnumSource`
D. `@CsvSource`

**Answer: B**

**Explanation:** A method can construct and return complex argument sets.

### 21. Which statement about `@CsvFileSource` is correct?

A. It requires the CSV data to be written directly inside the annotation.  
B. It supplies CSV data from a file.  
C. It is only for enum values.  
D. It creates dynamic tests.

**Answer: B**

**Explanation:** The defining distinction is the external CSV file.

### 22. Which statement about `@ArgumentsSource` is correct?

A. It is a mechanism for a custom argument provider.  
B. It can only provide integers.  
C. It is another name for `@ValueSource`.  
D. It identifies a lifecycle method.

**Answer: A**

**Explanation:** It provides a customizable way to supply arguments.

### 23. A test has this structure:

```java
int result = calculator.add(a, b);
assertEquals(expected, result);
```

Only `a`, `b`, and `expected` change across cases. What is the strongest reason to parameterize it?

A. The assertion is invalid.  
B. The test logic is repeated while only the data changes.  
C. JUnit cannot execute ordinary tests.  
D. The calculator needs dependency injection.

**Answer: B**

**Explanation:** This is exactly the duplication parameterized testing is intended to reduce.

### 24. Which statement is true?

A. Parameterized testing eliminates the need for assertions.  
B. Parameterized tests still use normal testing principles such as Arrange → Act → Assert.  
C. Parameterized tests cannot contain Java code.  
D. Parameterized tests are always dynamic tests.

**Answer: B**

**Explanation:** Parameterization changes how test data is supplied; it does not remove normal test structure.

### 25. What is the key relationship in parameterized testing?

A. One test structure + multiple argument sets  
B. One assertion + multiple test classes  
C. One lifecycle method + multiple production classes  
D. One application + multiple JUnit versions

**Answer: A**

**Explanation:** This is the central mental model.

# Parameterized vs Dynamic

### 26. Which statement best distinguishes a parameterized test from a dynamic test?

A. Parameterized tests use multiple supplied arguments; dynamic tests are generated programmatically at runtime.  
B. Parameterized tests are JUnit 4 features; dynamic tests are JUnit 3 features.  
C. Parameterized tests cannot be executed; dynamic tests can.  
D. They are exactly the same feature.

**Answer: A**

**Explanation:** The mechanisms solve different problems: data-driven invocations versus programmatically generated tests.

### 27. Which is the best mental model for a dynamic test?

A. One test structure with simple integer values  
B. A test case generated programmatically at runtime  
C. A test that always runs before another test  
D. A test loaded from a CSV file

**Answer: B**

**Explanation:** Dynamic tests are generated rather than being ordinary statically declared test methods.

### 28. Which statement about test templates is most accurate at this level?

A. They are identical to `@ValueSource`.  
B. They provide a mechanism for executing a test structure according to an invocation context.  
C. They are used only for CSV files.  
D. They replace assertions.

**Answer: B**

**Explanation:** A test template is an advanced invocation mechanism; its extension machinery is beyond the main practical focus here.

# Argument Conversion

### 29. What is the purpose of argument conversion?

A. To convert a test into production code  
B. To make supplied argument data usable as the parameter type when supported  
C. To convert assertions into lifecycle methods  
D. To convert JUnit 4 into JUnit 3

**Answer: B**

**Explanation:** JUnit can convert supplied source values into compatible parameter types in supported situations.

### 30. Consider:

```java
@ValueSource(strings = {"1", "2", "3"})
void test(int number) { }
```

What concept is relevant?

A. Test ordering  
B. Argument conversion  
C. Dynamic test generation  
D. Test interface inheritance

**Answer: B**

**Explanation:** The source provides strings while the test parameter expects an `int`, so conversion is relevant.

### 31. Which statement is most accurate?

A. Argument sources and argument conversion are the same feature.  
B. Argument sources supply data; conversion can make that data usable as the required parameter type.  
C. Conversion supplies data while sources perform assertions.  
D. Neither has anything to do with parameterized tests.

**Answer: B**

**Explanation:** The source answers **where the arguments come from**; conversion addresses **how supplied values become the required parameter type**.

# Dependency Injection / Parameter Resolution

### 32. Consider:

```java
@Test
void testSomething(TestInfo testInfo) {
    // ...
}
```

What is the important idea?

A. The developer must always construct `TestInfo` manually.  
B. JUnit can resolve and supply certain supported parameters.  
C. `TestInfo` is an assertion.  
D. `TestInfo` is a production dependency.

**Answer: B**

**Explanation:** JUnit's parameter-resolution mechanism can supply supported objects to test/lifecycle methods.

### 33. Which distinction is most accurate?

A. Normal Java parameters are always supplied by JUnit.  
B. JUnit-resolved parameters can be supplied by JUnit's parameter-resolution mechanism.  
C. JUnit never supplies method parameters.  
D. Parameter resolution is the same as `@ValueSource`.

**Answer: B**

**Explanation:** JUnit has a mechanism for resolving certain supported parameters.

### 34. Which is the better Pareto treatment of `TestInfo`, `RepetitionInfo`, and `TestReporter`?

A. Ignore their existence completely.  
B. Memorize every internal implementation detail.  
C. Understand that JUnit can inject certain supported objects into test/lifecycle methods, while leaving deep resolver details for later.  
D. Treat them as assertions.

**Answer: C**

**Explanation:** Recognition and role are useful; the full extension mechanism has lower immediate teaching value.

### 44. Which statement is the most accurate?

### 49. Which concept answers the question, "Where does the parameterized test get its data?"

### 50. Which concept answers the question, "How does supplied source data become the parameter type expected by the test?"
